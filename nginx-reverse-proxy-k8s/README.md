# Nginx Reverse Proxy K8s

Manifest for Nginx reverse proxy in kubernetes

# How To

0. Make a cup of coffee :)
1. Adjust public IP and domain in configmap.yaml
2. Set domain in ingress.yaml 
3. Apply service.yaml, configmap.yaml, deployment.yaml & ingress.yaml
4. Test in your local
5. Pointing in your DNS Management
6. Done
